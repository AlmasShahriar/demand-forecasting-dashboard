# Demand Forecasting Dashboard

## Overview
This project analyzes demand data and generates a simple dashboard for insights.

## Project Structure
demand-forecasting-dashboard/
├── generate_dashboard.py
├── data/
│   └── demand_data.csv
└── output/
    └── dashboard.html

## How to Run
1. Install Python
2. Install pandas:
   pip install pandas
3. Run:
   python generate_dashboard.py

## Output
Open this file in browser:
output/dashboard.html

## Key Features
- Demand data analysis
- Product-wise aggregation
- HTML dashboard generation
